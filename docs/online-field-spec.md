# ストーリー版の話データに入れる「オンライン用」の欄

オンライン対戦（記述ファイト）は、ストーリー版の話データ（`episodes/epNNN.js`）を**読むだけ**で、ストーリー版には何も書き込みません。
新しい話を作るときに、章ボスと同じ話データの中に、次の `online` の欄も一緒に作ってください。欄がない話は、今までどおり章ボスの記述1問だけがオンラインに出ます。

## ストーリー版で新しい話を作るときの頼み方

> 第N話を追加して。論点は私のノートの〇〇。いつもの紙芝居とキーワード選びの形で作って、話データには科目の印と、オンライン用の欄（短い紙芝居、別の聞き方の問題、ひっかけキーワード）も一緒に入れて。既存の話と本体は触らないで。

## 形

```js
LB.episode({
  no: 13,
  title: "…",
  subject: "民法",            // 科目の印：民法 / 行政法 / 憲法 / 商法 / 一般知識。オンラインに出るのは「民法」「行政法」だけ
  // …（いつもの話・章ボスはそのまま）…
  online: {
    // 対戦の最初に見せる短い紙芝居（3コマ）。2人が同時に見る。何を書かせる問題かが分かる物語に
    story: [
      { nar: "…", figs: [["hero","l","佐藤"],["boss","r","権田"]], say: { side: "r", text: "…", evil: 1 }, bg: "dark" },
      { nar: "…", figs: [ … ] },
      { nar: "…", figs: [ … ], bg: "red" }
    ],
    // 3ラウンドの問題。同じ事件から、別の論点か、同じ論点の別の聞き方（例：裁判所は何ができるか／自分はどんな訴えを起こせるか）
    rounds: [
      {
        inter: [ { nar: "…", figs: [ … ] } ],       // ラウンドの前に挟む続きの場面（1〜2コマ。1ラウンド目は空でよい）
        q: "…（40字程度で書かせる問い）",
        keys: [                                       // 正解キーワード（それだけで意味の通る文。3〜5個）
          { t: "伊藤が無資力である", label: "債務者の無資力" }
        ],
        decoys: [                                     // ひっかけ（それらしいが書いたら誤り。6個以上。why＝自爆したときの解説）
          { t: "伊藤の同意を得て取り消す", why: "債権者が裁判所に請求して行使する。債務者の同意はいらない。" }
        ],
        model: "…（解答例）",
        exp: "…（解説・条文）",
        law: "詐害行為取消権"                          // 論点名（終わったときに表示）
      },
      { … }, { … }
    ]
  }
});
```

## 決まりごと
- ストーリー版の本体（index.html）と、ほかの話のファイルは変えない。
- 論点は行政書士試験のど真ん中の頻出論点。条文・判例と食い違わないこと（ゲームのために論点を変えない）。
- キーワードは単語でなく、それだけで日本語として意味の通る文にする。
- ナレーションの声は、ストーリー版と同じように自動で録音される。
