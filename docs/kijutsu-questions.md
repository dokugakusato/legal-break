## 1. 弁済の提供と供託（493条・494条）（民法・ノート 民法 前編 1）

**事件**：荒野のはずれ、レストラン「砂嵐亭」。店主Aは毎月50万円の家賃を大家Bに払ってきた。 大家B「今月から家賃は70万円だ。70万円でなければ受け取らん！」 Aが50万円を差し出しても、Bは受け取りを拒み続ける。このままでは債務不履行で追い出されかねない。 店主A「払う準備はできているのに…。責任を免れ、家賃の債務からも解放されるにはどうすればいい！？」

**問題**：Bがあらかじめ受領を拒んでいる。Aが債務不履行の責任を免れ、さらに債務を消滅させるには、どのような手段をとればよいか。

**正解キーワード（4つ・各5点）**：【弁済の準備をしたことを通知する】【受領の催告をする】【Bの受領拒絶を理由に供託する】【債務の履行地の供託所に供託する】

**解答例**：弁済の準備をしたことを通知してその受領の催告をし（口頭の提供）、Bが受領を拒んだことを理由として、債務の履行地の供託所に供託すればよい。

**ひっかけ（1試合で4つ出る）**：
- Bの住所地の供託所に供託する … 供託所は債務の履行地の供託所（495条1項）。
- 50万円を持参して現実に提供する … あらかじめ受領を拒まれているときは、口頭の提供で足りる（493条ただし書）。
- Bに履行の催告をする … 催告するのは「受領」。履行の催告は債権者が債務者にするもの。
- 家賃と敷金を相殺する … 相殺では債務不履行の責任を免れる手段にならない。問われているのは弁済の提供と供託。
- Bの承諾を得て供託する … 供託に債権者の承諾はいらない。受領拒絶を理由にできる（494条1項1号）。
- 裁判所に家賃の減額を請求する … 問われているのは責任を免れ債務を消す手段＝口頭の提供と供託。

**解説**：債権者があらかじめ受領を拒んでいるときは、弁済の準備をしたことを通知してその受領の催告をすれば足りる（口頭の提供・493条ただし書）。弁済の提供をすれば債務不履行の責任を免れる（492条）。さらに、弁済の提供をしたのに債権者が受領を拒んだときは供託でき（494条1項1号）、供託は債務の履行地の供託所にする（495条1項）。供託すれば債務は消滅する。

確認：□ OK　□ 直す（　　　　　　　　）

## 2. 第三者弁済（474条）（民法・ノート 民法 前編 2）

**事件**：荒野の金貸しBは、Aに100万円を貸していた。Aの友人Xは、Aを助けようと代わりに返済を申し出た。 金貸しB「Aの借金はAから返してもらう！ 赤の他人の金なんぞ受け取らん！」 XはAの親友だが、法律上の利害関係はない。Bは第三者からの弁済を拒んでいる。 友人X「それでも俺が払える道はないのか？ Aと手を組めば…！」

**問題**：弁済をするについて正当な利益を有しない第三者Xが、債権者Bの意思に反して弁済できるのは、どのような場合か。

**正解キーワード（4つ・各5点）**：【債務者Aの委託を受けて弁済する】【委託のことを債権者Bが知っている】【正当な利益のない第三者でも弁済できる】【Bの意思に反しても有効になる】

**解答例**：Xが債務者Aの委託を受けて弁済をする場合において、そのことを債権者Bが知っていたとき。

**ひっかけ（1試合で4つ出る）**：
- 債権者Bの承諾を得て弁済する … 必要なのは債務者の委託と、それを債権者が知っていること（474条3項ただし書）。
- 委託のことをBが知ることができた … 「知ることができた」では足りない。債権者が知っていたことが必要。
- XがAの保証人になってから弁済する … 保証人になる話ではない。委託を受けた第三者として弁済する。
- Bの意思に反する弁済は常に無効 … 債務者の委託を受け、そのことを債権者が知っていれば有効（474条3項ただし書）。
- Aの意思に反しても常に有効 … 債務者の意思に反する弁済は原則できない（474条2項）。
- Xは代物弁済しかできない … 代物弁済の話ではない。第三者による弁済そのものができる。

**解説**：債務の弁済は第三者もできる（474条1項）。弁済をするについて正当な利益を有しない第三者は、債権者の意思に反して弁済できないが、その第三者が債務者の委託を受けて弁済をする場合において、そのことを債権者が知っていたときは弁済できる（同条3項）。なお、債務者の意思に反する弁済は原則できないが、債権者が債務者の意思に反することを知らなかったときは有効（同条2項）。

確認：□ OK　□ 直す（　　　　　　　　）

## 3. 差押えと相殺（511条）（民法・ノート 民法 前編 3）

**事件**：BはA銀行に400万円の定期預金を持つ。一方でA銀行はBに400万円を貸し付けていた。 ところがBは国税を滞納していた。国税Cは、BのA銀行に対する定期預金債権を差し押さえた。 A銀行「預金を持っていかれたら、うちの貸付金は回収できなくなる！ 相殺で守りたい！」 国税C「差押えたのはこちらが先だ。銀行の相殺など認めん！」

**問題**：差押えを受けた預金債権について、A銀行が貸付金債権との相殺を差押債権者Cに対抗できるのは、どのような場合か。

**正解キーワード（4つ・各5点）**：【差押え前に貸付金債権を取得している】【貸付金債権を自働債権とする】【預金債権と相殺する】【相殺を差押債権者Cに対抗できる】

**解答例**：A銀行が差押え前に自働債権（貸付金債権）を取得していたときは、その債権による相殺をもって差押債権者Cに対抗することができる。

**ひっかけ（1試合で4つ出る）**：
- 差押え後に取得した債権でも常に相殺できる … 差押え後に取得した債権では、原則として相殺を対抗できない（511条1項）。
- 弁済期が差押え前に来ていることが必要 … 判例・511条は、差押え前に取得していれば弁済期の先後を問わない（無制限説）。
- 預金債権を自働債権とする … 銀行が持つ貸付金債権が自働債権。預金債権は受働債権。
- 相殺を債務者Bにだけ対抗できる … 問題は差押債権者Cに対抗できるか。差押え前取得ならCに対抗できる。
- Cの承諾を得て相殺する … 相殺は単独行為。差押債権者の承諾はいらない。
- 代物弁済で預金を消す … 問われているのは相殺。代物弁済には債権者の承諾が要る別の制度。

**解説**：差押えを受けた債権の第三債務者（A銀行）は、差押え後に取得した債権による相殺をもって差押債権者に対抗できないが、差押え前に取得した債権による相殺をもって対抗できる（511条1項）。改正後の511条は弁済期の先後を問わない（いわゆる無制限説を条文化）。差押え後に取得した債権でも、差押え前の原因に基づいて生じたものなら相殺を対抗できるが、差押え後に他人から取得した債権は除かれる（同条2項）。

確認：□ OK　□ 直す（　　　　　　　　）

## 4. 錯誤と重過失（95条3項）（民法・ノート 民法 前編 4）

**事件**：骨董商Aは、10万円の壺を1万円と書き間違えて値札を付け、客Bに売ってしまった。 骨董商A「しまった！ 桁を間違えた！ この売買、取り消させてくれ！」 客B「それはお前の重大な過失だろう。取り消しなど認めんぞ。」 表意者に重大な過失があるとき、錯誤による取消しは原則できない。だが例外がある――。

**問題**：錯誤が表意者Aの重大な過失によるものであっても、Aが意思表示を取り消すことができるのは、どのような場合か。2つ挙げよ。

**正解キーワード（4つ・各5点）**：【相手方が錯誤を知っていた】【相手方が重大な過失で錯誤を知らなかった】【相手方も同一の錯誤に陥っていた】【重過失のある表意者でも取り消せる】

**解答例**：相手方が表意者に錯誤があることを知り、又は重大な過失によって知らなかったとき、及び相手方が表意者と同一の錯誤に陥っていたとき。

**ひっかけ（1試合で4つ出る）**：
- 相手方が錯誤を知ることができた … 「知ることができた」（軽過失）では足りない。知り、又は重大な過失で知らなかったとき（95条3項1号）。
- 表意者が動機の錯誤に陥っていた … 動機の錯誤は取消しの要件の話。重過失があっても取り消せる例外の話ではない。
- 錯誤は無効を主張できる … 改正後の錯誤は「取消し」（95条1項）。
- 善意無過失の相手方にも取り消せる … 例外は相手方の悪意・重過失か共通錯誤のとき。
- 表意者に軽い過失しかなかった … 問題は表意者に重過失がある場合の例外。
- 相手方が錯誤を追認した … 追認の話ではない。

**解説**：錯誤が表意者の重大な過失によるものであった場合には、原則として取り消せない。ただし、①相手方が表意者に錯誤があることを知り、又は重大な過失によって知らなかったとき、②相手方が表意者と同一の錯誤に陥っていたときは、取り消すことができる（95条3項）。動機の錯誤は、その事情が法律行為の基礎とされていることが表示されていたときに限り取り消せる（同条2項）。

確認：□ OK　□ 直す（　　　　　　　　）

## 5. 虚偽表示の第三者と二重譲渡（94条2項・177条）（民法・ノート 民法 前編 5）

**事件**：悪党Aは差押えを逃れるため、仲間Bと通謀して土地をBに売ったことにし、登記もBに移した。 Bはその土地を、事情を知らないCに売った。一方Aも「通謀だから無効だ」と、同じ土地をDに売った。 買主C「私はBから買った。仮装なんて知らなかったぞ！」 買主D「私は本当の持ち主Aから買ったんだ！ この土地は私のものだ！」

**問題**：Bから買い受けたCが、Aから買い受けたDに対して土地の所有権を主張できるのは、どのような場合か。

**正解キーワード（4つ・各5点）**：【Cが虚偽表示について善意である】【94条2項の第三者として保護される】【CとDは対抗関係に立つ】【Dより先に所有権移転登記を備える】

**解答例**：Cが虚偽表示につき善意であり、かつ、Dより先に所有権移転登記を備えたとき。

**ひっかけ（1試合で4つ出る）**：
- Cが善意無過失である … 94条2項の第三者は善意であれば足り、無過失はいらない（判例）。
- Bより先に登記を備える … 争う相手はDなので、Dより先に登記を備える。
- 先に引渡しを受ける … 不動産の二重譲渡は登記の先後で決まる（177条）。
- Cが虚偽表示を知っていた … 悪意の第三者は94条2項で保護されない。
- 先に代金を払う … 代金を払った順ではなく、登記の先後で決まる。
- Dは登記がなくてもCに勝つ … CとDは対抗関係。登記を先に備えた方が勝つ。

**解説**：通謀虚偽表示は無効だが、その無効は善意の第三者に対抗できない（94条2項）。第三者は善意であればよく、無過失は不要（判例）。善意のCとAから買ったDとは、Aを起点とする二重譲渡の関係になり、先に登記を備えた方が優先する（177条、最判昭42.10.31）。

確認：□ OK　□ 直す（　　　　　　　　）

## 6. 取消訴訟と執行停止（行訴法25条）（行政法・ノート 行政法 1）

**事件**：荒野の町で食堂を営むAに、知事から営業停止処分が下された。Aは処分の取消訴訟を起こした。 店主A「裁判をしている間にも店は止められたまま…。このままじゃ店がつぶれる！」 取消訴訟を起こしても、処分の効力は止まらない。これを執行不停止の原則という。 佐藤「止める道はある。裁判所に頼め。ただし、要件を書けなければ話にならんぞ。」

**問題**：取消訴訟が係属している場合に、裁判所が処分の執行停止をすることができるのは、どのようなときに、どのような方法によってか。

**正解キーワード（4つ・各5点）**：【重大な損害を避けるため】【緊急の必要がある】【申立てにより】【決定で執行停止する】

**解答例**：処分の執行等により生ずる重大な損害を避けるため緊急の必要があるときに、申立てにより、決定をもって執行停止をすることができる。

**ひっかけ（1試合で4つ出る）**：
- 回復の困難な損害を避けるため … 平成16年改正で「重大な損害」に緩められた（行訴法25条2項）。
- 償うことのできない損害を避けるため … それは仮の義務付け・仮の差止めの要件（37条の5）。
- 裁判所が職権で執行停止する … 執行停止は申立てにより行う（25条2項）。
- 判決で執行停止する … 執行停止は決定でする（25条2項）。
- 取消訴訟を起こせば当然に執行が止まる … 執行不停止の原則（25条1項）。
- 公共の福祉のため必要がある … 公共の福祉に重大な影響を及ぼすおそれがあれば、むしろ執行停止できない（25条4項）。

**解説**：取消訴訟の提起は処分の効力等を妨げない（執行不停止の原則・行訴法25条1項）。重大な損害を避けるため緊急の必要があるときは、裁判所は申立てにより決定をもって執行停止ができる（同条2項）。重大な損害かどうかは、損害の回復の困難の程度を考慮し、損害の性質・程度、処分の内容・性質も勘案する（同条3項）。公共の福祉に重大な影響を及ぼすおそれがあるとき、又は本案について理由がないとみえるときはできない（同条4項）。

確認：□ OK　□ 直す（　　　　　　　　）

## 7. 許可の取消しと撤回（行政法・ノート 行政法 2）

**事件**：砂利採取業者Aは、知事から採取の認可を受けて営業していた。 ところが調べてみると、Aは偽の書類を使い、不正な手段で認可を受けていたことが分かった。 知事「こんな認可、最初から無かったことにしてやる！ だが法律に消せると書いていなくても消せるのか？」 佐藤「行政法学上の呼び名、効果、法律の根拠。この3つを書き切れ。」

**問題**：成立の時点から違法な瑕疵があった認可を、知事が消滅させる行為は、行政法学上何と呼ばれ、どのような効果を持ち、法律の根拠を要するか。

**正解キーワード（4つ・各5点）**：【行政法学上の取消しである】【成立時からの瑕疵が理由】【効果は遡及して消える】【法律の根拠はいらない】

**解答例**：行政法学上取消しといい、その効果は遡及的に消滅し、法律の根拠は不要である。

**ひっかけ（1試合で4つ出る）**：
- 行政法学上の撤回である … 撤回は、成立後の事情で将来に向かって効力を失わせるもの。成立時の瑕疵なら取消し。
- 効果は将来に向かってだけ消える … 将来効は撤回。取消しは遡及する。
- 法律の根拠が必要である … 職権取消しに法律の根拠はいらない（判例・通説）。
- 失効したものとして扱う … 失効は期限の到来などで当然に効力を失うこと。
- 裁判所の判決がなければ消せない … 処分庁が職権で取り消せる。
- 無効確認をする … 無効確認は訴訟の話。行政庁が消す行為は取消し。

**解説**：成立時から瑕疵がある行政行為の効力を失わせるのが「取消し」で、効果は遡及する。成立後の事情（違反行為など）を理由に将来に向かって効力を失わせるのが「撤回」。いずれも法律の明文の根拠は不要とされる。取消しは処分庁・上級行政庁ができるが、撤回は処分庁のみ。受益的処分の取消し・撤回は、相手方の利益を考えて制限されることがある。

確認：□ OK　□ 直す（　　　　　　　　）

## 8. 聴聞の期日にできること（行手法20条2項）（行政法・ノート 行政法 3）

**事件**：宅地建物取引業者Aは、違反を重ねたとして免許取消しの処分を受けそうになっている。 免許取消しのような重い不利益処分の前には、意見陳述の手続として聴聞が開かれる。 業者A「聴聞の日に出ていって、何ができるんだ？ 言いたいことは山ほどある！」 佐藤「40字で書けるようにしておけ。聴聞の三点セットだ。」

**問題**：聴聞の通知を受けたAは、聴聞の期日に出頭して、どのようなことができるか。

**正解キーワード（4つ・各5点）**：【聴聞の期日に意見を述べる】【証拠書類等を提出する】【主宰者の許可を得る】【行政庁の職員に質問する】

**解答例**：意見を述べ、及び証拠書類等を提出し、並びに主宰者の許可を得て行政庁の職員に対し質問を発することができる。

**ひっかけ（1試合で4つ出る）**：
- 弁明書を提出する … 弁明書は弁明の機会の付与の手続（行手法29条）。
- 行政庁の許可を得て質問する … 許可をするのは主宰者（行手法20条2項）。
- 審理員の許可を得る … 審理員は行政不服審査法の手続。聴聞は主宰者。
- 職員を証人として尋問する … 尋問ではなく「質問を発する」。
- 反論書を提出する … 反論書は審査請求の手続（行審法30条）。
- 主宰者の許可なく質問できる … 質問には主宰者の許可が要る。

**解説**：当事者は聴聞の期日に出頭して、意見を述べ、証拠書類等を提出し、主宰者の許可を得て行政庁の職員に質問を発することができる（行手法20条2項）。出頭に代えて、聴聞の期日までに陳述書及び証拠書類等を提出することもできる（21条1項）。不利益処分をするときは、原則として同時に理由を示さなければならない（14条1項）。

**正解キーワード（4つ・各5点）**：【供用目的に沿った利用との関連】【利用者以外の第三者に対する危険】【危害を生ぜしめる危険性がある】【設置管理の瑕疵に含まれる】

**解答例**：営造物が供用目的に沿って利用されることとの関連において、その利用者以外の第三者に対して危害を生ぜしめる危険性がある場合も含まれる。

**ひっかけ（1試合で4つ出る）**：
- 空港に物理的な欠陥があることが必要 … 物理的欠陥がなくても、供用関連瑕疵として含まれる（大阪空港訴訟）。
- 利用者に対する危険に限られる … 利用者以外の第三者に対する危険も含む。
- 管理者に過失があることが必要 … 国賠法2条は無過失責任。
- 予算が足りなければ免責される … 予算の制約は免責理由にならない（判例）。
- 不可抗力でも責任を負う … 不可抗力は免責される。
- 国家賠償法1条の責任である … 営造物の設置管理の瑕疵は2条。

**解説**：2条1項の「設置又は管理の瑕疵」は、営造物が通常有すべき安全性を欠いていることをいい、物理的欠陥だけでなく、営造物が供用目的に沿って利用されることとの関連において、その利用者以外の第三者に対して危害を生ぜしめる危険性がある場合も含む（最大判昭56.12.16・大阪空港訴訟、供用関連瑕疵・機能的瑕疵）。2条は無過失責任。道路は予算不足を理由に免責されないが（高知落石事件）、河川は過渡的な安全性で足りる（大東水害訴訟）。※ノートの「共用」は、判例では「供用」。

## 18. 条例制定の処分性（水道料金条例）（行政法・ノート 行政法 8）

**事件**：荒野町は、別荘地の水道料金を大幅に値上げする条例を制定した。 別荘主X「この条例は不当だ！ 条例の制定そのものを取消訴訟で取り消してやる！」 だが、取消訴訟の対象は「行政庁の処分その他公権力の行使に当たる行為」に限られる。 佐藤「裁判所はどんな理由で、どんな判決を出すか。「処分性」で考えろ。」

**問題**：水道料金を改定する条例の制定行為の取消しを求める訴えについて、裁判所はどのような理由で、どのような判決をするか。

**正解キーワード（4つ・各5点）**：【条例は料金を一般的に改定する】【限られた特定の者に適用されない】【制定行為は処分に当たらない】【訴えを却下する】

**解答例**：本件条例は、水道料金を一般的に改定するものであって、限られた特定の者に対してのみ適用されるものではなく、その制定行為は抗告訴訟の対象となる行政処分に当たらないから、訴えを却下する。

**ひっかけ（1試合で4つ出る）**：
- 請求を棄却する … 処分性がないので訴え自体が不適法＝却下。
- 制定行為は処分に当たる … 一般的に料金を改定する条例は処分に当たらない（判例）。
- 条例を取り消す判決をする … 処分性がないので取り消せない。
- 保育所廃止条例と同じく処分に当たる … 保育所廃止条例は特定の者に直接適用されるので処分性あり。本件は一般的な改定。
- 民事訴訟で争うので却下 … 理由は処分性がないこと。
- 料金改定は違法なので取り消す … 中身の判断に入る前に却下。

**解説**：水道料金を一般的に改定する条例は、限られた特定の者に対してのみ適用されるものではなく、その制定行為は抗告訴訟の対象となる行政処分に当たらない（最判平18.7.14・高根町事件）。処分性がないので訴えは却下（門前払い）。これに対し、保育所廃止条例は、他に行政庁の処分を待つことなく保育所廃止の効果を生じ、入所中の児童・保護者という限られた特定の者に直接影響するので、処分と実質的に同視でき処分性がある（最判平21.11.26）。

## 19. 釈明処分の特則（行訴法23条の2）（行政法・ノート 行政法 9）

**問題**：取消訴訟において、裁判所は、訴訟関係を明瞭にするため、行政庁に対してどのようなことができるか。被告側の行政庁と、それ以外の行政庁に分けて述べよ。

**正解キーワード（4つ・各5点）**：【被告側の行政庁に資料の提出を求める】【処分の理由を明らかにする資料】【それ以外の行政庁に送付を嘱託する】【訴訟関係を明瞭にするため】

**解答例**：裁判所は、被告側の行政庁に対し、処分の理由を明らかにする資料であって当該行政庁が保有するものの全部又は一部の提出を求め、被告側以外の行政庁に対しては、その資料の送付の嘱託をすることができる。

**ひっかけ（1試合で4つ出る）**：
- 被告側の行政庁に資料の提出を命じる … 「命じる」ではなく「求める」（行訴法23条の2）。
- 原告に資料の提出を求める … 対象は行政庁。
- 処分の違法を明らかにする資料 … 「処分の理由を明らかにする資料」。
- 他の行政庁に資料を送達する … 「送付の嘱託」。
- 職権で証拠調べをする … それは24条の職権証拠調べ。
- 証拠保全を申し立てる … 釈明処分の特則とは別の制度。

**解説**：釈明処分の特則（行訴法23条の2第1項）：裁判所は、①被告である国・公共団体に所属する行政庁又は被告である行政庁に対し、処分の内容・根拠法令・原因事実その他処分の理由を明らかにする資料の全部又は一部の提出を求め、②それ以外の行政庁に対しては、その資料の送付を嘱託することができる。裁判所の権限であって義務ではなく、行政庁にも提出義務はない（拒めば心証に影響しうる）。

## 20. 申請型義務付け訴訟と仮の義務付け（行政法・ノート 行政法 10）

**事件**：Aは娘を荒野市の保育園に入れようと申し込んだが、市は入園不許可の処分をした。 母A「こんな不許可は違法だわ！ 取消訴訟を起こしてやる！」 佐藤「取消判決を取っても、入園できるとは限らない。それに裁判には時間がかかる。」 判決が出るころには、娘は入園の時期を逃してしまう――。

**問題**：娘を早期に入園させるため、Aは、どのような訴えを提起し、どのような申立てをすべきか。

**正解キーワード（4つ・各5点）**：【不許可処分の取消訴訟を起こす】【入園承諾の義務付けの訴えを起こす】【2つの訴えを併合提起する】【仮の義務付けを申し立てる】

**解答例**：不許可処分の取消訴訟と、入園を承諾すべき旨を命ずることを求める義務付けの訴えを併合提起し、あわせて仮の義務付けの申立てをすべきである。

**ひっかけ（1試合で4つ出る）**：
- 執行停止を申し立てる … 不許可処分を止めても入園できない。仮の義務付け（37条の5）。
- 差止めの訴えを起こす … 差止めはこれからされる処分を止める訴え。
- 仮の差止めを申し立てる … 入園させたいので仮の義務付け。
- 義務付けの訴えだけを起こす … 申請型は取消訴訟などとの併合提起が必要（37条の3第3項）。
- 無効確認の訴えだけを起こす … 取消訴訟（又は無効等確認）と義務付けを併合。
- 先に審査請求をしなければならない … 本件で審査請求前置は求められていない。

**解説**：申請が拒否された場合の義務付けの訴え（申請型）は、拒否処分の取消訴訟又は無効等確認の訴えを併合して提起しなければならない（行訴法37条の3第3項）。義務付けの訴えの提起があった場合、処分がされないことにより生ずる償うことのできない損害を避けるため緊急の必要があり、かつ、本案について理由があるとみえるときは、裁判所は申立てにより、決定をもって仮の義務付けができる（37条の5第1項）。公共の福祉に重大な影響を及ぼすおそれがあるときはできない（同条3項）。

確認：□ OK　□ 直す（　　　　　　　　）

## 21. 取得時効と占有の推定（162条・186条）（民法・ノート 民法 前編 11）

**事件**：Aは、荒野の一角の土地を自分のものだと信じて、10年間、畑として耕し続けてきた。 ある日、本当の持ち主Bが現れ「その土地を返せ」と迫った。Aは10年の取得時効を主張する。 持ち主B「時効だと言うなら、所有の意思も善意も平穏も公然も、全部お前が証明してみろ！」 佐藤「全部を証明する必要はない。何が推定され、何を立証すれば足りるか書け。」

**問題**：Aが10年の取得時効を主張する場合に、Aは何を立証すれば足りるか。その理由とともに述べよ。

**正解キーワード（4つ・各5点）**：【所有の意思・善意・平穏・公然は推定される】【10年間占有したことを立証する】【占有開始時の無過失を立証する】【無過失は推定されない】

**解答例**：占有者は所有の意思をもって、善意で、平穏に、かつ、公然と占有するものと推定されるから、10年間の占有と、占有開始の時に無過失であったことを立証すれば足りる。

**ひっかけ（1試合で4つ出る）**：
- 無過失も推定される … 186条1項で推定されるのは所有の意思・善意・平穏・公然。無過失は推定されない（判例）。
- 所有の意思を自分で立証する … 所有の意思は推定される（186条1項）。
- 20年間占有したことを立証する … 善意無過失なら10年（162条2項）。
- 善意を自分で立証する … 善意は推定される。
- 所有の意思はみなされる … 「みなす」ではなく「推定」。反証で覆る。
- 占有の継続を毎年立証する … 前後の両時点の占有で継続が推定される（186条2項）。

**解説**：10年の取得時効は、所有の意思をもって平穏かつ公然と他人の物を占有し、占有開始時に善意・無過失であることが要件（162条2項）。占有者は所有の意思をもって善意で平穏かつ公然と占有するものと推定される（186条1項）が、無過失は推定されない（判例）。前後の両時点で占有した証拠があれば、その間は占有が継続したと推定される（同条2項）。

## 22. 代理権の濫用（107条）（民法・ノート 民法 前編 12）

**事件**：Aは、不動産にくわしいBに頼んで、自分の土地を売る代理権を与えた。 Bはさっそく土地をCに売り、登記も移した。だがBは、最初から代金を着服するつもりだった。 地主A「代金は一円も届いていない！ この売買、なかったことにしたい！」 佐藤「代理権の範囲内でも、目的が悪ければ扱いが変わる。相手方Cの事情がカギだ。」

**問題**：Bが自己の利益を図る目的で代理行為をした場合、その行為はどのように扱われるか。また、AはCに対してどうすれば契約の効力を否定できるか。

**正解キーワード（4つ・各5点）**：【Cが濫用の目的を知り又は知ることができた】【代理権を有しない者の行為とみなされる】【本人Aに効果は帰属しない】【AはCに追認を拒絶する】

**解答例**：相手方Cがその目的を知り、又は知ることができたときは、Bの行為は代理権を有しない者がした行為とみなされるので、AはCに対して追認の拒絶をすればよい。

**ひっかけ（1試合で4つ出る）**：
- Cが重大な過失で知らなかったときに限る … 「知ることができた」（過失）で足りる（107条）。
- Bの行為は当然に無効 … 無権代理行為とみなされる。追認の余地がある。
- 表見代理が成立する … 濫用の目的を知り得た相手方は保護されない。
- AはCに取消しを主張する … 無権代理なので、追認を拒絶すればよい。
- AはCに追認すればよい … 追認すると効果が帰属してしまう。
- Cが善意無過失でも否定できる … Cが善意無過失なら有効な代理行為。

**解説**：代理人が自己又は第三者の利益を図る目的で代理権の範囲内の行為をした場合、相手方がその目的を知り、又は知ることができたときは、その行為は代理権を有しない者がした行為（無権代理）とみなされる（107条）。本人が追認しなければ本人に効力を生じないので（113条1項）、追認を拒絶すればよい。善意の相手方は、本人が追認しない間は取り消すこともできる（115条）。

## 23. 自己契約・双方代理（108条）（民法・ノート 民法 前編 13）

**事件**：Aは、自分の家を売るため、不動産にくわしいBに代理権を与えた。 Bは「いい買主が見つかりました」と契約を結んだ。ところが、その買主はB自身だった。 家主A「代理人が自分で買うなんて、それはずるいだろう！」 佐藤「これを自己契約という。原則の扱いと、例外として許される場合を書け。」

**問題**：代理人Bが自ら買主となって契約した場合（自己契約）、その行為はどのように扱われるか。また、例外として許されるのはどのような場合か。

**正解キーワード（4つ・各5点）**：【自己契約は無権代理とみなされる】【債務の履行は例外】【本人があらかじめ許諾した行為は例外】【例外の行為は有効】

**解答例**：代理権を有しない者がした行為とみなされる。ただし、債務の履行及び本人があらかじめ許諾した行為については、この限りでない。

**ひっかけ（1試合で4つ出る）**：
- 自己契約は当然に無効 … 無権代理行為とみなされる（108条1項）。追認の余地がある。
- 本人が事後に承諾すれば例外になる … 例外は「あらかじめ」許諾した行為。事後なら追認の問題。
- 相手方が承諾すれば例外になる … 本人の許諾が必要。
- 自己契約は取り消すことができる … 取消しではなく、無権代理とみなされる。
- 利益相反行為はすべて有効 … 利益相反行為も無権代理とみなされる（108条2項）。
- 債務の履行も許されない … 債務の履行は例外として許される。

**解説**：同一の法律行為について、相手方の代理人として（自己契約）、又は当事者双方の代理人として（双方代理）した行為は、代理権を有しない者がした行為とみなされる。ただし、債務の履行及び本人があらかじめ許諾した行為は除く（108条1項）。それ以外でも、代理人と本人との利益が相反する行為は、本人があらかじめ許諾したものを除き、無権代理とみなされる（同条2項）。

確認：□ OK　□ 直す（　　　　　　　　）

## 25. 動産の先取特権と占有改定（333条）（民法・ノート 民法 前編 15）

**事件**：大家Xは、Aに建物を貸している。Aは建物の中に、高価な精密機械を置いていた。 Aはその機械をBに売ったが、置き場のないBのために、機械はそのままAが預かることになった。 やがてAは家賃を滞納した。Xは、機械に先取特権を行使して家賃を回収しようとする。 買主B「機械はもうおれのものだ。たとえ建物の中にあってもな！」

**問題**：機械がAの建物内に置かれたままの場合、Xは機械について先取特権を行使できるか。その理由とともに述べよ。

**正解キーワード（4つ・各5点）**：【第三取得者に引き渡すと行使できない】【占有改定も引渡しに含まれる】【機械は占有改定で第三取得者に渡った】【Xは先取特権を行使できない】

**解答例**：先取特権は、債務者が目的動産を第三取得者に引き渡した後は行使できず、占有改定も引渡しに含まれるから、Xは先取特権を行使できない。

**ひっかけ（1試合で4つ出る）**：
- 占有改定は引渡しに含まれない … 判例は、占有改定も333条の引渡しに含まれるとする。
- 機械がAの建物にあるので行使できる … 占有改定で引き渡されているので行使できない。
- 即時取得の問題になる … 333条の追及効の制限の問題。
- 物上代位で機械そのものに行使できる … 物上代位は代金債権などに対するもの（304条）。
- 登記をすれば行使できる … 動産の先取特権に登記はない。
- 現実の引渡しだけが引渡しに当たる … 占有改定も含まれる（判例）。

**解説**：先取特権は、債務者がその目的である動産をその第三取得者に引き渡した後は、その動産について行使できない（333条）。この「引渡し」には占有改定も含まれる（大判大6.7.26）。これに対し、即時取得（192条）は占有改定では成立しない（判例）。横断的に問われやすい。

## 26. 再審査請求の棄却（行審法64条3項）（行政法・ノート 行政法 11）

**事件**：荒野の食堂主Aは、営業停止処分を受け、知事に審査請求をしたが、棄却された。 Aは知事の裁決に手続の違法を見つけ、大臣に再審査請求をした。 店主A「知事の裁決は違法だ！ 取り消されて当然だろう！」 佐藤「裁決が違法でも、再審査請求が棄却される場合がある。もとの処分に目を向けろ。」

**問題**：原裁決が違法又は不当である場合でも、再審査庁が裁決で再審査請求を棄却するのは、どのようなときか。

**正解キーワード（4つ・各5点）**：【原裁決等が違法又は不当である】【処分自体は違法でも不当でもない】【裁決で判断する】【再審査請求を棄却する】

**解答例**：原裁決等が違法又は不当である場合においても、当該審査請求に係る処分が違法又は不当のいずれでもないときは、再審査庁は、裁決で当該再審査請求を棄却する。

**ひっかけ（1試合で4つ出る）**：
- 再審査請求を却下する … 要件を満たした請求なので却下ではなく棄却（行審法64条3項）。
- 原裁決を取り消す … 処分が適法・妥当なら、原裁決を取り消しても意味がないので棄却。
- 決定で判断する … 再審査請求は裁決。
- 事情裁決をする … 事情裁決は処分が違法・不当だが公益上取り消さない場合。
- 公の利益に著しい障害が必要 … それは事情裁決の要件。
- 処分を変更する … 変更の話ではない。

**解説**：再審査請求は、原裁決又は当初の処分を対象とする（行審法6条2項）。原裁決等が違法又は不当である場合でも、審査請求に係る処分が違法又は不当のいずれでもないときは、再審査庁は裁決で再審査請求を棄却する（64条3項）。もとの処分に問題がなければ、裁決を取り消しても結論は変わらないから。

確認：□ OK　□ 直す（　　　　　　　　）

## 27. 争点訴訟（収用裁決の無効と所有権確認）（行政法・ノート 行政法 12）

**事件**：荒野のXの土地は、B市の道路用地として、県の収用委員会の収用裁決により収用された。 Xは裁決に納得していなかったが、取消訴訟も起こさないまま出訴期間が過ぎた。 B市が工事を始めると、Xは「あの裁決は無効だ、土地はおれのものだ！」と言い出した。 佐藤「無効等確認の訴えには補充性がある。現在の法律関係で争う道を考えろ。」

**問題**：収用裁決が無効であると考えるXは、誰を被告として、どのような訴えを提起すべきか。また、その訴えは何と呼ばれるか。

**正解キーワード（4つ・各5点）**：【B市を被告とする】【土地の所有権確認の訴えを起こす】【収用裁決の無効が前提問題になる】【争点訴訟と呼ぶ】

**解答例**：Xは、B市を被告として、土地の所有権の確認の訴えを提起すべきであり、これを争点訴訟という。

**ひっかけ（1試合で4つ出る）**：
- 収用委員会を被告とする … 民事訴訟なので、権利を争う相手（起業者B市）が被告。
- 県を被告とする … 収用委員会の所属する県ではなく、起業者B市。
- 収用裁決の無効確認の訴えを起こす … 現在の法律関係に関する訴え（所有権確認）で目的を達するので、無効確認ではない。
- 形式的当事者訴訟と呼ぶ … 形式的当事者訴訟は損失補償の訴えなど。
- 損失補償の増額を求める … Xは収用を無効と考えている。補償の話ではない。
- 取消訴訟を起こす … 無効を主張する民事訴訟＝争点訴訟。

**解説**：私法上の法律関係に関する訴訟で、処分の存否又は効力の有無が争われているものを争点訴訟という（行訴法45条）。所有権確認訴訟という「現在の法律関係に関する訴え」で目的を達せられるので、収用裁決の無効等確認の訴えは補充性（36条）により原則として提起できない。なお、補償金額に不満なら、起業者を被告とする形式的当事者訴訟（土地収用法133条）による。

## 28. 町村総会（地方自治法94条）（行政法・ノート 行政法 13）

**事件**：荒野の果ての小さな村。住民は百人足らずで、議員のなり手もいない。 村長「議会を開くのも一苦労だ。いっそ村人みんなで決められんものか…。」 普通地方公共団体には議会を置くのが原則だ（地方自治法89条）。 佐藤「町村には例外がある。何によって、何を置けるか書け。」

**問題**：町村が議会を置かないことができるのは、どのような方法によって、どのような機関を設ける場合か。

**解答例**：町村は、条例で、議会を置かず、選挙権を有する者の総会を設けることができる。

## 29. 審査請求の認容と審査庁の立場（行審法46条）（行政法・ノート 行政法 14）

**事件**：荒野の商人Aは、営業許可の取消処分に対して審査請求をした。 審理の結果、処分は重すぎると判断された。審査庁は処分をどう直せるのか。 商人A「取消しじゃなくて、せめて営業停止に軽くしてくれ！」 佐藤「審査庁が処分庁か、上級行政庁か、そのどちらでもないかで、できることが違う。」

**問題**：処分についての審査請求に理由がある場合、審査庁は裁決でどのようなことができるか。審査庁の立場の違いに注意して述べよ。

**正解キーワード（4つ・各5点）**：【上級行政庁か処分庁なら取消しができる】【上級行政庁か処分庁なら変更もできる】【それ以外の審査庁は変更できない】【それ以外の審査庁も取消しはできる】

**解答例**：処分庁の上級行政庁又は処分庁である審査庁は、処分の全部又は一部を取り消し、又はこれを変更することができるが、そのいずれでもない行政庁である審査庁は、処分を変更することはできない。

**ひっかけ（1試合で4つ出る）**：
- どの審査庁も処分を変更できる … 上級行政庁でも処分庁でもない審査庁は変更できない（行審法46条1項ただし書）。
- 処分を撤廃する … 「撤廃」は事実上の行為（47条）の話。
- 違法を宣言するだけ … 違法の宣言は事情裁決。
- 処分庁の同意を得れば変更できる … 同意で変更できるようにはならない。
- どの審査庁も取消しができない … 理由があれば取り消せる。
- 審査会が裁決する … 裁決するのは審査庁。

**解説**：処分についての審査請求に理由がある場合、審査庁は裁決で処分の全部若しくは一部を取り消し、又はこれを変更する。ただし、審査庁が処分庁の上級行政庁又は処分庁のいずれでもない場合は、変更はできない（行審法46条1項）。申請拒否処分を取り消す場合で一定の処分をすべきと認めるときは、上級行政庁は処分庁に処分すべき旨を命じ、処分庁は自ら処分をする（同条2項）。審査請求人の不利益に変更することはできない（48条）。

確認：□ OK　□ 直す（　　　　　　　　）

## 30. 自己の法律上の利益に関係のない違法（新潟空港訴訟）（行政法・ノート 行政法 15）

**事件**：国は、ある航空会社に、荒野空港を使う定期航空運送事業の免許を与えた。 騒音に悩む周辺住民が、免許の取消訴訟を起こした。原告適格は認められた。 住民「滑走路は航空法違反だ！ 乗客の大半は遊びのツアー客で、免許の基準にも合わない！」 佐藤「その主張は、お前たちの騒音被害と関係があるか？ 裁判所の判断を書け。」

**問題**：周辺住民が、騒音被害と関係のない違法（滑走路の違法や利用客の構成など）のみを主張した場合、裁判所はどのような理由で、どのような判決をするか。

**正解キーワード（4つ・各5点）**：【自己の法律上の利益に関係のない違法】【それを理由に取消しを求められない】【訴えは適法に審理される】【請求を棄却する】

**解答例**：取消訴訟においては、自己の法律上の利益に関係のない違法を理由として取消しを求めることができないから、請求を棄却する。

**ひっかけ（1試合で4つ出る）**：
- 訴えを却下する … 周辺住民には原告適格がある。主張が制限されるだけなので棄却（行訴法10条1項）。
- 原告適格がない … 騒音被害を受ける住民には原告適格がある（新潟空港訴訟）。
- 処分を取り消す … 自己の利益と関係のない違法しか主張していないので取り消せない。
- 第三者の利益の違法も主張できる … 自己の法律上の利益に関係のない違法は主張できない。
- 訴えの利益がない … 訴えの利益の問題ではない。
- 公益を理由に取り消せる … 主張できない。

**解説**：取消訴訟においては、自己の法律上の利益に関係のない違法を理由として取消しを求めることができない（行訴法10条1項）。新潟空港訴訟（最判平元.2.17）では、周辺住民の原告適格は認められたが、騒音被害と関係のない違法の主張は許されず、請求は棄却された（訴えの適法性の問題ではないので却下ではなく棄却）。

確認：□ OK　□ 直す（　　　　　　　　）
