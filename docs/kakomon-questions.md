## 1. 令和5年 本試験 問44｜議員の出席停止と差止め

**事件**：Y市議会。議員Xは、議場での発言を問題にされた。 「次の9月議会で、Xを出席停止の懲罰にかける」 出席停止になれば、Xは議会で一切活動できない。 「懲罰が決まってしまう前に、止められないのか」 かつては「議会の内部の問題」として、裁判所は口を出さないとされていた。だが最高裁は、令和2年に考えを改めた。 「議会のことに裁判所は関係ない！」 出題：Xは、行政事件訴訟法のどの訴えと仮の救済で、懲罰を事前に止めるべきか。 「処分が出る前に止める道だ。誰を相手に、何をする？」

**問題**：これからされる出席停止の懲罰を止めたいXは、誰を被告として、どのような訴えを提起し、あわせてどのような申立てをすべきか。

**正解キーワード（4つ・各5点）**：【Y市を被告とする】【出席停止の懲罰の差止めの訴えを起こす】【あわせて仮の差止めを申し立てる】【出席停止は司法審査の対象になる】

**解答例**：Y市を被告として、出席停止の懲罰の差止めの訴えを提起し、あわせて仮の差止めを申し立てる。

**ひっかけ（1試合で4つ出る）**：
- Y市議会を被告とする … 被告は処分をした行政庁が所属する地方公共団体＝Y市（行訴法11条1項）。
- 議長を被告とする … 行政庁が所属する地方公共団体（Y市）が被告。
- 執行停止を申し立てる … 執行停止はすでにされた処分を止めるもの。まだされていない処分は仮の差止め（37条の5第2項）。
- 懲罰の取消訴訟を起こす … 懲罰はまだされていない。これからの処分を止めるのは差止めの訴え（37条の4）。
- 議会の内部の問題なので争えない … 出席停止の懲罰は司法審査の対象になる（最大判令和2年11月25日）。
- 義務付けの訴えを起こす … 求めているのは懲罰をさせないこと＝差止め。

**解説**：地方議会議員の出席停止の懲罰は、司法審査の対象となる（最大判令和2年11月25日。従来の判例を変更）。これからされる処分を止めるには差止めの訴え（行訴法37条の4）を提起し、仮の救済として仮の差止め（37条の5第2項）を申し立てる。被告は処分をする行政庁の所属する地方公共団体＝Y市（11条1項）。

## 2. 令和5年 本試験 問45｜抵当権の物上代位（火災保険金）

**事件**：金貸しAは、Bに金を貸し、B所有の建物甲に抵当権をつけていた。 「この建物が担保だ。忘れるなよ」 ある夜、建物甲が火事で焼け落ちた。 「建物が…全部燃えちまった！」 甲には火災保険がかけてあった。保険会社から、Bに保険金が払われようとしている。 「保険金はまもなくBさんにお支払いします」 出題：Aは、どのような法的手段で、いつまでに何をすれば、保険金から優先して回収できるか。 「抵当権は消えちゃいない。ただし、間に合わせろ」

**問題**：建物甲が焼失し、Bに火災保険金が支払われようとしている。抵当権者Aが保険金から優先弁済を受けるには、どのような法的手段により、何をしなければならないか。

**正解キーワード（4つ・各5点）**：【抵当権に基づく物上代位をする】【火災保険金の請求権を差し押さえる】【Bに払い渡される前に差し押さえる】【保険金から優先して弁済を受ける】

**解答例**：抵当権に基づく物上代位により、Bへの保険金の払渡し前に、火災保険金請求権を差し押さえなければならない。

**ひっかけ（1試合で4つ出る）**：
- 払い渡された後でも差し押さえればよい … 払渡し又は引渡しの前に差し押さえなければならない（372条・304条1項ただし書）。
- 差し押さえずに保険会社に請求できる … 物上代位には差押えが必要（304条1項ただし書）。
- 建物が焼けたので抵当権は何もできない … 抵当権は目的物に代わる保険金請求権に及ぶ（物上代位・372条・304条）。
- 債権者代位権を行使する … 問われているのは抵当権の優先弁済。手段は物上代位。
- 詐害行為取消権を行使する … Bは財産を逃がしたわけではない。物上代位の問題。
- Bの承諾を得て保険金を受け取る … 承諾はいらない。払渡し前の差押えが必要。

**解説**：抵当権は、目的物の滅失によって債務者が受けるべき金銭その他の物（火災保険金請求権を含む）に対しても行使できる（物上代位・372条・304条1項）。ただし、その払渡し又は引渡しの前に差押えをしなければならない（304条1項ただし書）。

## 3. 令和5年 本試験 問46｜請負の契約不適合責任

**事件**：Aは大工Bに、家を建てる仕事を頼んだ（請負契約）。 「立派な家を建ててやるよ」 完成した家に住みはじめると、屋根の3か所から雨漏りがした。 「雨のたびに水びたしだ…」 Aは、雨漏りのことをすぐBに知らせた。だがBは、直すのは面倒だと言う。 「直せと言われてもなあ」 出題：Aは、何を根拠に、修補のほかにどんな請求や権利行使ができるか。 「修理だけじゃない。根拠と、残り3つを言え」

**問題**：請負で建てた家に雨漏り（契約の内容に適合しない）があり、AはBにその旨を通知した。Aは、何を根拠として、修補の請求以外にどのような権利を行使できるか。

**正解キーワード（4つ・各5点）**：【請負人の担保責任を根拠とする】【報酬の減額を請求する】【損害賠償を請求する】【契約を解除する】

**解答例**：請負人の担保責任に基づき、報酬の減額請求、損害賠償請求及び契約の解除をすることができる。

**ひっかけ（1試合で4つ出る）**：
- 建物なので契約の解除はできない … 改正で旧635条ただし書（建物は解除不可）は削除された。解除できる（559条・564条・541条・542条）。
- 引渡しから1年以内に訴えを起こす … 不適合を知った時から1年以内に「通知」すれば足りる（637条1項）。Aはもう通知している。
- 錯誤を理由に契約を取り消す … 問われているのは担保責任（契約不適合責任）に基づく権利。
- 不法行為だけを根拠とする … 根拠は請負人の担保責任（契約不適合責任・559条→562条以下）。
- Bの同意を得て解除する … 解除は一方的な意思表示でできる。Bの同意はいらない。
- 代金の全額返還だけを請求できる … 減額請求・損害賠償・解除ができる。

**解説**：請負には売買の担保責任の規定が準用される（559条）。注文者は、修補（追完）請求のほか、報酬減額請求（563条）、損害賠償請求（564条・415条）、契約の解除（564条・541条・542条）ができる。改正で建物の解除を禁じた旧635条ただし書は削除された。注文者は不適合を知った時から1年以内に通知する必要がある（637条1項）。

## 4. 令和6年 本試験 問44｜競願と取消訴訟

**事件**：荒野に1つだけ空いた放送の枠。XとAが、そろって総務大臣Yに免許を申請した。 「免許をとるのは俺だ！」 Yは、Aに免許を与え、Xの申請は拒否した。 「免許はAに。Xは不許可だ」 枠は1つしかない。Aへの免許がある限り、Xに免許が出ることはない。 「どれを、誰を相手に争えばいいんだ…」 出題：Xは、誰を被告として、どの処分の取消訴訟を提起できるか。 「取消せる処分は1つじゃない。被告もまちがえるな」

**問題**：競願の結果、Aに免許処分、Xに拒否処分がされた。Xは、誰を被告として、どのような取消訴訟を提起することができるか。

**正解キーワード（4つ・各5点）**：【国を被告とする】【Aへの免許処分の取消訴訟を起こす】【自分への拒否処分の取消訴訟を起こす】【どちらの取消訴訟でも争える】

**解答例**：国を被告として、Aに対する免許処分の取消訴訟又はXに対する拒否処分の取消訴訟を提起できる。

**ひっかけ（1試合で4つ出る）**：
- 総務大臣を被告とする … 被告は処分をした行政庁が所属する国（行訴法11条1項）。
- Aを被告とする … 取消訴訟の被告は行政主体（国）。Aは被告ではない。
- 拒否処分を取り消しても意味がない … 競願関係では、拒否処分が取り消されれば審査をやり直すことになるので、訴えの利益がある（判例・東京12チャンネル事件）。
- 義務付けの訴えをあわせて起こす … 問われているのは取消訴訟。義務付けを書くと得点にならないとされる。
- 免許の取消しは民事訴訟で争う … 処分の取消しは抗告訴訟（取消訴訟）で争う。
- まず審査請求をしなければならない … 自由選択主義（8条1項）。前置は求められていない。

**解説**：競願関係にある者は、他者への免許処分の取消訴訟を提起できるほか、自己への拒否処分の取消訴訟を提起することもできる（最判昭和43年12月24日・東京12チャンネル事件）。拒否処分が取り消されれば、行政庁は改めて審査をやり直すことになるので、訴えの利益がある。被告は処分をした行政庁（総務大臣）が所属する国（行訴法11条1項）。

## 5. 令和6年 本試験 問45｜動産売買の先取特権

**事件**：商人Aは、Bに機械甲を売り、引き渡した。代金はあとで払う約束だった。 「代金は来月まとめて払うよ」 ところがBは代金を払わない。甲は、誰にも転売されないまま、Bの倉庫にしまわれている。 「金はない。払えんものは払えん」 Bにはほかにも借金がたくさんある。このままでは、ほかの債権者と分け合うことになる。 「せめて、売った甲からは先に取り返したい」 出題：Aは、どのような権利に基づき、どのようにして代金を確保できるか。 「売った物そのものに、お前の権利がついている」

**問題**：売った動産甲がBの倉庫に転売されずに残っている。代金を払ってもらえない売主Aは、どのような権利に基づき、どのようにして代金を確保できるか。

**正解キーワード（4つ・各5点）**：【動産売買の先取特権に基づく】【甲を差し押さえる】【甲を競売にかける】【競売代金から優先して弁済を受ける】

**解答例**：動産売買の先取特権に基づき、甲を差し押さえて競売し、その競売代金から優先して弁済を受ける。

**ひっかけ（1試合で4つ出る）**：
- 転売代金に物上代位する … 甲は転売されていない。甲そのものに先取特権を行使する。物上代位の記述は得点にならないとされる。
- 甲を倉庫から持ち帰る … 自力救済は許されない。差押え・競売の手続による。
- 留置権を行使する … Aはすでに甲を引き渡しているので、留置権はない。
- 先取特権の登記をする … 動産の先取特権は法律上当然に生じ、登記はいらない（311条5号・321条）。
- ほかの債権者と平等に配当を受ける … 先取特権により、ほかの債権者に先立って弁済を受けられる（303条）。
- 詐害行為取消権を行使する … Bは財産を逃がしたわけではない。

**解説**：動産の売主は、その動産の代価と利息について、その動産の上に先取特権を有する（311条5号・321条）。目的動産が債務者のもとにあれば、差押え・競売の手続（民事執行法190条）によって、その売却代金から他の債権者に先立って弁済を受けられる（303条）。転売されて第三取得者に引き渡された後は追及できない（333条）。

## 6. 令和6年 本試験 問46｜登記請求権の代位行使

**事件**：土地は、C→B→Aと売られた。だが登記は、まだCの名義のままだ。 「買ったのに、登記が自分にならない」 BはCに「登記を移してくれ」と言えるのに、何もしない。 「まあ、そのうちにな…」 AはCから直接、自分に登記を移してもらうことはできない。 「お前に売った覚えはないぞ」 出題：Aは、何のために、BのCに対するどんな権利を、どのように行使できるか。 「Bが動かないなら、Bの権利を代わりに使え」

**問題**：土地がC→B→Aと売られたが、登記はCのまま。BはCへの登記請求をしない。Aは、何のために、どのような権利を、どのように行使できるか。

**正解キーワード（4つ・各5点）**：【AのBに対する登記請求権を保全するため】【BのCに対する登記請求権を】【Bに代わって行使できる】【Bが無資力でなくてもよい】

**解答例**：AのBに対する登記請求権を保全するため、BのCに対する登記請求権を代位行使できる。

**ひっかけ（1試合で4つ出る）**：
- Bが無資力であることが必要 … 登記請求権の代位（423条の7）では、債務者の無資力はいらない。
- Cに直接Aへの移転登記を求める … AとCは直接の売買関係にない。中間省略登記は原則として請求できない。
- BのCに対する代金債権を代位する … 代位するのは、BのCに対する「登記請求権」。
- 詐害行為取消権を行使する … Bは財産を逃がしたわけではない。
- Cに所有権確認の訴えだけを起こす … 登記を移すには、Bの登記請求権を代位行使する。
- Bの承諾を得てから行使する … 代位行使に債務者の承諾はいらない。

**解説**：登記をしなければ第三者に対抗できない財産を譲り受けた者は、その譲渡人が第三者に対して有する登記手続請求権を行使しないときは、その権利を行使することができる（423条の7・登記請求権の代位）。債務者の無資力は要件ではない。

## 7. 令和7年 本試験 問44｜裁決の取消訴訟（原処分主義）

**事件**：Y市長から不利益な処分を受けたXは、審査請求をした。 「この処分はおかしい。審査請求だ！」 審査請求は棄却された。しかも、その審理の手続には、法律に反するところがあった。 「棄却。以上だ」 Xが争いたいのは、もとの処分ではなく、裁決の手続そのものの違法だ。 「裁決のやり方が違法なんだ！」 出題：Xは、何を主張して、誰を被告に、どんな訴えを起こすべきか。 「処分の違法と裁決の違法。どこで争うかは決まっている」

**問題**：審査請求を棄却する裁決の手続に違法があった。その違法を争いたいXは、何を主張して、誰を被告として、どのような訴えを提起すべきか。

**正解キーワード（4つ・各5点）**：【裁決固有の瑕疵を主張する】【Y市を被告とする】【裁決の取消しの訴えを起こす】【原処分の違法は処分の取消訴訟で争う】

**解答例**：裁決固有の瑕疵を主張して、Y市を被告として、裁決の取消しの訴えを提起する。

**ひっかけ（1試合で4つ出る）**：
- 裁決の取消訴訟で原処分の違法も主張する … 裁決の取消訴訟では、処分の違法を理由として取消しを求めることができない（行訴法10条2項・原処分主義）。
- Y市長を被告とする … 被告は行政庁が所属する地方公共団体＝Y市（11条1項）。
- 国を被告とする … 処分も裁決もY市の機関がした。被告はY市。
- 再審査請求をしてからでないと訴えられない … 再審査請求は法律に定めがある場合にできるだけ。前置ではない。
- 処分の取消訴訟で裁決の手続の違法を争う … 裁決の手続の違法（裁決固有の瑕疵）は、裁決の取消訴訟で争う。
- 裁決の無効確認しかできない … 出訴期間内なら裁決の取消訴訟を提起できる。

**解説**：処分の取消しの訴えと、審査請求を棄却した裁決の取消しの訴えとを提起できる場合、裁決の取消しの訴えでは、処分の違法を理由として取消しを求めることができない（行訴法10条2項・原処分主義）。裁決の手続の違法など、裁決固有の瑕疵は裁決の取消しの訴えで主張する。被告は行政庁の所属する地方公共団体（11条1項）。

## 8. 令和7年 本試験 問45｜日常家事と表見代理

**事件**：AとBは夫婦。B名義の土地があった。 「その土地は、私の名義だからね」 Aは、Bに頼まれてもいないのに、Bの代理人としてその土地をCに売った。 「夫婦なんだ。妻の代わりに売っても問題ない」 Bは、契約は無効だと言う。Cは、夫婦なら当然代理できると思っていた。 「そんな契約、私は知らない！」 出題：Cが保護され、Bが契約の効果を否定できないのは、どんなときか。 「夫婦の代理権には範囲がある。判例の言い回しで書け」

**問題**：夫AがBの代理人として、B名義の土地をCに売った。Cが保護され、Bが本件契約の効果を否定できないのはどのような場合か。

**正解キーワード（4つ・各5点）**：【日常家事の範囲内だとCが信じた】【そう信じたことに正当な理由がある】【表見代理の規定を類推適用する】【日常家事代理権を基本代理権としない】

**解答例**：Cにおいて、本件契約がABの日常の家事に関する法律行為の範囲内に属すると信ずるにつき正当な理由があるとき。

**ひっかけ（1試合で4つ出る）**：
- 日常家事代理権を基に110条を直接適用 … 判例は、日常家事代理権を基本代理権として110条を直接適用することは否定している（最判昭和44年12月18日）。
- Cが善意であれば足りる … 日常家事の範囲内に属すると信ずるにつき「正当な理由」が必要。
- 夫婦なら当然に互いの財産を処分できる … 761条の日常家事の代理権は、日常の家事に関する法律行為に限られる。
- Bが追認しない限り常に無効 … 正当な理由があれば、110条の趣旨の類推適用でCは保護される。
- AとBが連帯して代金返還の責任を負う … 761条の連帯責任の話ではない。契約の効果がBに及ぶかの問題。
- Aに代理権があるとCが信じたとき … 信じる対象は「日常家事の範囲内に属すること」（判例）。

**解説**：夫婦の一方が日常の家事に関する代理権の範囲を超えて第三者と法律行為をした場合、その代理権を基本代理権として110条を直接適用することは、夫婦の財産的独立をそこなうので許されない。ただし、第三者においてその行為がその夫婦の日常の家事に関する法律行為の範囲内に属すると信ずるにつき正当の理由があるときは、110条の趣旨を類推適用して第三者を保護する（最判昭和44年12月18日）。

## 9. 令和7年 本試験 問46｜事務管理の継続と費用償還

**事件**：隣人Bは長い旅に出ている。そこへ大嵐が来て、Bの家の屋根が吹き飛んだ。 「このままじゃ、Bの家が水びたしになる！」 Aは頼まれてもいないのに、自分の金で修理を始めた。 「材料代は立て替えておこう」 途中でAは疲れてしまった。修理をやめてもいいのか。払った材料代はどうなるのか。 「もうやめたい…。お金は返ってくるのか？」 出題：Aは修理を続けなければならないか。かかった費用をBに請求できるか。 「頼まれずに始めた仕事にも、ルールがある」

**問題**：留守中の隣人Bの家を、頼まれずに修理し始めたA。Aは修理を途中でやめてよいか。また、支出した費用をBに請求できるか。

**正解キーワード（4つ・各5点）**：【事務管理が成立する】【Bが管理できるまで修理を続ける】【Bのための有益な費用を請求できる】【報酬は請求できない】

**解答例**：事務管理者の管理継続義務に基づき修理を継続し、Bのために有益な費用としてその償還を請求できる。

**ひっかけ（1試合で4つ出る）**：
- いつでも自由に修理をやめてよい … 本人等が管理できるまで、事務管理を継続しなければならない（700条）。
- 修理の報酬を請求できる … 事務管理では原則として報酬は請求できない。
- 費用に利息を付けて請求できる … 702条は有益費の償還を定めるが、委任（650条）と違い利息の規定はない。
- Bの承諾がないので費用は請求できない … 事務管理が成立すれば、本人のために支出した有益な費用は償還請求できる（702条1項）。
- 不法行為として損害賠償を請求する … 問われているのは事務管理の費用償還。
- Bの意思に反しても常に全額請求できる … 本人の意思に反するときは、現に利益を受けている限度でのみ（702条3項）。

**解説**：義務なく他人のために事務の管理を始めた者は、本人等が管理できるに至るまで事務管理を継続しなければならない（700条）。管理者は、本人のために有益な費用を支出したときは、本人に対しその償還を請求できる（702条1項）。本人の意思に反して管理したときは、本人が現に利益を受けている限度に限られる（同条3項）。報酬や利息の請求は認められない。
