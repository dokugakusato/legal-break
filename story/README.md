# LEGAL BREAK アニメ化 指示書（新しい窓に貼る用）

あなたは、行政書士試験の学習ゲーム「LEGAL BREAK ―法の拳―」をアニメ（動画）にする担当です。
ゲームは別の窓で作り続けています。**物語はゲームと共通**なので、ゲームのデータを読んで使います。

## 1. 物語と素材のある場所

GitHub のリポジトリ `dokugakusato/legal-break`（ゲーム本体。公開サイトは https://legal-break.5ukaku.com/ ）

| 何 | 場所 | 説明 |
|---|---|---|
| 全話の台本 | `story/STORY.md` | 第0.1〜0.3話（令和8年本試験版）と第1話〜最新話。オープニング、事件、ナレーション、台詞、ボス戦、結末、次回予告 |
| 登場人物 | `story/CHARACTERS.md` | キャラ絵の名前と、話ごとの役名、見た目の説明 |
| 台本の作り直し | `node tools/story_bible.mjs` | ゲームに話が増えたら、これを実行すると上の2つが最新になる |
| 各話の元データ | `episodes/ep001.js`〜、`episodes/hon01.js`〜 | 台本の元。**ゲームの窓が管理しているので、アニメの窓では書きかえない** |
| キャラ絵 | `index.html` と `kijutsu.js` の `SIL` | SVG（ベクター）の影絵ふう人物。`mk(...)` の中身がそのまま絵。佐藤は `hero` |
| 顔アイコン | `faces/*.png` | 関係図に使う顔 |
| 録音ずみの声 | `audio/*.mp3` と `audio/manifest.json` | VOICEVOX で録った全台詞。manifest に「話者｜設定｜台詞」が入っている |
| 声の配役 | `tools/gen_voice.mjs` の `CAST` | ナレーション＝青山龍星、佐藤＝玄野武宏 など。アニメでも同じ声を使う |
| 音楽 | `index.html` / `kijutsu.js` の `TR` | ブラウザで鳴らす自作の曲（ファイルではない）。使うなら録音して書き出す |

## 2. 守ること（ゲームと同じ決まり）

- 人物・団体・事件は**すべて架空**。動画にも「この物語はフィクションです」と入れる。
- **実在の警察・役所・団体を悪役にしない**。警察署名などは「荒野西署」のような架空のもの。
- **残酷な表現はしない**。血や刃物で倒さない。敵はギャグでぶっ飛ばす（百裂拳、ちゃぶ台返し、ホームラン、ボウリング、押し出し など）。
- かわいそうな立場の人が負ける話では、痛みを感じない「慈悲の法拳」で送る。
- 法律の中身は正確に。条文・判例は台本（STORY.md）の記述と模範解答に合わせる。
- 個人情報（メールアドレス、住所、電話番号）は動画にも説明欄にも出さない。
- 実在の作品のキャラクターや絵をまねしない（佐藤のサングラス姿などはゲームのオリジナル）。

## 3. 読み方（声を作るときは必ず）

| 字 | 読み |
|---|---|
| 荒野 | こうや |
| 金（単独のとき） | カネ |
| 留置権・留置 | りゅうちけん・りゅうち（**絶対に** とめおき と読まない） |
| 現る | あらわる |
| 札 | ふだ（札束 は さつたば） |
| いちばん上・一番上 | いちばんうえ（じょう と読まない） |
| 取消（送りがなのないもの） | 取り消し |

ゲームの読みの決まりは `tools/gen_voice.mjs` の `yomi` にまとまっている。

## 4. 主な登場人物（くわしくは CHARACTERS.md）

- **佐藤**：主人公。独学で戦う人を応援する行政書士。黒いサングラス。法の拳で悪をぶっ飛ばす。
- **荒野の町の人々**：加藤（直売所）、中村（加藤の店を手伝う若者）、佐々木（行商人）、田中（老農夫）、松本（酒店の女将）、さや など。
- **悪役**：黒崎組（黒崎）、役場の課長・権堂、県の灰原、詐欺師の白鷺、謎の組織「荒野会」の霧島 など。
- 第37話から「荒野会」が役所や信用金庫とつながる陰謀の話が続いている。

## 5. 進め方

- アニメの作業ファイルは、**ゲームのリポジトリとは別の場所**（新しい非公開のリポジトリなど）に置く。ゲームのリポジトリは公開されているので、未発表の映像や台本をそこに置かない。
- ゲームのリポジトリからは**読むだけ**。台本を直したいときは、ゲームの窓に頼む（ゲームの話を直す → `node tools/story_bible.mjs` で台本を作り直す）。
- 最初の1本は、持ち主と相談して決める。候補：
  - 第1話「意思表示編」をそのまま 3〜5分のアニメに
  - オープニング映像（1分）
  - 予告編・PV（30〜60秒）
  - 第0.1〜0.3話（令和8年本試験版）
- 画面の形：YouTube 横長 16:9 か、ショート・TikTok 縦長 9:16。両方なら横で作って縦に切り出す。
- 料金がかかるサービスには登録しない（カード情報は入れない）。無料でできる範囲で進める。
